# Changelog — 2026-09-17

## Fixed

- **Voice `AbortError: The operation was aborted` on `/say` and `/join`** — upgraded `@discordjs/voice` from `0.17.0` to `0.19.2`; the old version only supported retired `xsalsa20_poly1305` encryption modes and voice gateway v4, so Discord dropped the handshake after OP 8 and `entersState(..., Ready, 15_000)` always timed out — the new version uses gateway v8 with AEAD encryption (`aead_aes256_gcm_rtpsize` / `aead_xchacha20_poly1305_rtpsize`) and DAVE (`@snazzah/davey`)
- **Stale voice connections reused after failed connects** — `say.ts`, `join.ts`, and `tts.ts` now call `connection.destroy()` when `entersState` times out, so the next command creates a fresh connection instead of reusing a half-open one
- **`/join` reported success on failed connects** — now replies with an error message and returns early instead of claiming the connection succeeded

## Changed

- **`package.json`** — `@discordjs/voice` bumped to `^0.19.2`; added `@noble/ciphers` as encryption fallback alongside `sodium-native`
- **`voice-state-update.ts`** — auto-reconnect now passes `selfDeaf: false` for consistency with `/join` and `/say`
